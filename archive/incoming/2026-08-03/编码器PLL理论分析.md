# 编码器 PLL 理论分析

## 1. PLL 在编码器中的作用

PLL（Phase-Locked Loop，锁相环）通过编码器测得的转子位置，估计连续、平滑的位置和速度。

在电机编码器中：

```text
相位 = 转子位置
频率 = 转子速度
```

相比直接使用相邻位置差分计算速度，PLL 不会把编码器量化噪声和采样噪声过度放大，更适合为速度环和 FOC 提供速度反馈。

## 2. 二阶 PLL 模型

定义：

- `θm`：编码器测量位置。
- `θ̂`：PLL 估计位置。
- `ω̂`：PLL 估计速度。
- `e = θm - θ̂`：位置误差。

当前编码器 PLL 对应的连续模型为：

```text
dθ̂/dt = ω̂ + Kp·e
dω̂/dt = Ki·e
e = θm - θ̂
```

它有估计位置和估计速度两个状态，因此是二阶 PLL，也可以理解为二阶位置观测器。

工作过程为：

1. 根据上一次估计速度预测当前位置。
2. 比较预测位置与编码器测量位置。
3. 使用位置误差修正估计位置。
4. 将持续的位置误差积分成速度修正量。

## 3. 开环与闭环传递函数

从位置误差到估计位置的开环传递函数为：

```text
       Kp·s + Ki
L(s) = ---------
          s²
```

系统包含两个积分环节，因此属于 Type-II PLL。

估计位置相对于测量位置的闭环传递函数为：

```text
 θ̂(s)       Kp·s + Ki
─────── = ----------------
 θm(s)   s² + Kp·s + Ki
```

特征方程为：

```text
s² + Kp·s + Ki = 0
```

与标准二阶系统比较：

```text
s² + 2ζωn·s + ωn² = 0
```

可以得到：

```text
ωn = √Ki
ζ  = Kp / (2√Ki)
```

其中：

- `ωn` 是自然频率，主要决定响应速度。
- `ζ` 是阻尼比，主要决定响应是否振荡。

## 4. 参数选择

常用的临界阻尼设计为：

```text
Kp = 2ωn
Ki = ωn²
```

此时：

```text
ζ = 1
```

临界阻尼可以在快速收敛和避免明显振荡之间取得平衡。

PLL 带宽存在以下权衡：

| 带宽 | 优点 | 缺点 |
| --- | --- | --- |
| 较高 | 加减速跟踪快、延迟小 | 更容易引入编码器噪声 |
| 较低 | 速度平滑、噪声抑制好 | 动态响应慢、加速时滞后大 |

## 5. 稳态跟踪能力

位置误差传递函数为：

```text
 e(s)          s²
─────── = ----------------
 θm(s)   s² + Kp·s + Ki
```

因此二阶 Type-II PLL 具有以下理论特性：

- 静止位置输入：稳态位置误差为 0。
- 恒定速度输入：稳态位置误差为 0。
- 恒定加速度输入：存在有限位置误差。

恒定加速度 `α` 下的位置稳态误差为：

```text
eθ = α / Ki
```

因此，PLL 在稳定匀速时可以准确跟踪；加减速越大，瞬时位置和速度滞后越明显。

## 6. 速度估计传递函数

PLL 估计速度相对于真实速度的传递函数为：

```text
 ω̂(s)          Ki
─────── = ----------------
 ωm(s)   s² + Kp·s + Ki
```

它相当于一个二阶低通系统：

- 低频增益趋近 1，可以正确跟踪稳定机械速度。
- 高频增益快速下降，可以抑制编码器量化噪声和位置抖动。

这也是 PLL 相比直接位置差分更适合速度估计的主要原因。

直接位置差分近似为：

```text
ω(s) = s·θ(s)
```

微分会放大高频噪声，而 PLL 在高频段会衰减测量噪声。

## 7. 环形位置处理

编码器位置是周期量，位置误差不能直接相减，必须限制在半圈范围内：

```text
-π < e ≤ π
```

例如测量位置从 `359°` 变化到 `1°`，真实变化是正向 `2°`，而不是反向 `358°`。

只有在 PLL 已经锁定、单次位置变化没有超过半圈时，前面的线性传递函数分析才成立。超过半圈可能发生周期滑移或方向误判。

## 8. 当前项目参数

当前项目采样频率为：

```text
fs = 20 kHz
Ts = 50 μs
```

PLL 参数为：

```text
ωn = 700 rad/s
Kp = 1400
Ki = 490000
ζ  = 1
```

自然频率换算为普通频率约为：

```text
fn = 700 / (2π) ≈ 111.4 Hz
```

变量名虽然写作 `BANDWIDTH_HZ`，但当前公式没有乘 `2π`，因此其中的 `700` 更接近以 `rad/s` 使用的自然频率参数。

当前无量纲采样参数为：

```text
ωn·Ts = 700 × 0.00005 = 0.035
```

该值远小于 1，说明采样频率相对于 PLL 动态足够高，离散实现与连续模型比较接近。

## 9. 总结

编码器 PLL 的本质是一个二阶闭环位置观测器：

```text
编码器测量位置
      ↓
与估计位置比较
      ↓
    位置误差
   ↙        ↘
修正位置    修正速度
   ↘        ↙
  预测下一时刻位置
```

其主要价值是：

- 从离散位置中估计连续机械速度。
- 抑制直接差分造成的量化噪声放大。
- 对静止位置和恒定速度实现零稳态位置误差。
- 通过自然频率和阻尼比调节响应速度与噪声之间的平衡。

对于稳定匀速工况，PLL 的理论跟踪效果很好；在快速加减速阶段，误差主要由机械加速度、`Ki` 和系统带宽决定。
