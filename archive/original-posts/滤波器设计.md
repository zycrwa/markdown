<font style="color:#DF2A3F;">运算放大器的核心参数：单位增益带宽（GBW）</font>

一般情况下，带宽*增益=常数；对于低频滤波，必须在截至之前，增益够大才能负反馈；GBW>10*闭环增益*最大工作频率



+ **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Q 小（如 < 0.707）</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：幅频响应曲线圆钝、平缓，通带内没有凸起，相位线性度好。 响应</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">过冲小，无振铃</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">，波形平滑。Q 值越小，响应越平缓  </font>
+ **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Q = 0.707</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：这是巴特沃斯（Butterworth）滤波器的标准值，通带 “最大平坦”。 响应有轻微过冲（约 4.3%），是临界阻尼状态。  </font>
+ **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">Q 大（如 > 0.707）</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：幅频响应会出现一个明显的 “峰值”，即通带内产生波纹（如切比雪夫 Chebyshev 滤波器），同时阻带衰减更陡峭。 响应会出现明显的</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">过冲和振铃</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">，Q 值越大，震荡越剧烈，恢复到稳态的时间越长。  </font>
