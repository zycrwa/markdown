# 待入库资料

本目录只存放尚未经过 AI 整理的资料。不要把原稿直接放进 `source/_posts/`，也不要在这里存放密码、密钥、个人隐私或无权公开的内容。

## 放置方式

一个主题使用一个子目录，把相关的 Markdown、代码和图片放在一起：

```text
inbox/
  motor-current-loop/
    notes.md
    waveform.png
    test-code.c
```

原稿允许是零散笔记，不要求 Front Matter 或正式排版。不同主题尽量拆开，同一问题的上下文、参数、代码和图片则不要分散到多个目录。

## 可选的原稿模板

```markdown
# 主题或暂定标题

## 我想解决的问题

说明应用场景、目标和已知条件。

## 原始记录

放入笔记、公式、代码、实验现象、参数和自己的推理。

## 来源

- [资料名称](https://example.com)
- 数据手册型号、书名和页码

## 待确认

- 哪些结论没有实际验证？
- 哪些资料互相冲突？
```

来源、适用条件和不确定性对 AI 很重要。无法确认的内容可以直接写“待确认”，不要为了让原稿看起来完整而补写猜测。

## 交给 AI

资料放好后可以直接发送：

```text
处理 inbox/<主题目录> 中的新资料。先检索现有知识库，判断应该合并到已有文章还是新建文章；保留来源和不确定性，本地化图片，更新知识索引并完成检查和构建。先不要提交、推送或发布。
```

AI 会先读取根目录的 `AGENTS.md` 和 `KNOWLEDGE_INDEX.md`，再精读候选文章。相同主题会合并，有关联但边界不同的主题才会新建并互相关联。

完成入库后，原稿会移动到 `archive/incoming/YYYY-MM-DD/`，归档路径会写入文章的 `source_docs`；整理后的正式文章才进入 `source/_posts/`。
