编码器 PLL 位置跟踪与速度估计

发表于 2026-08-03 更新于 2026-08-24 分类于 电机控制
分析编码器二阶 PLL 的连续模型、传递函数、稳态跟踪能力、环形位置处理与参数选择；具体控制环设计由关联文章维护。

编码器 PLL（Phase-Locked Loop，锁相环）利用离散的转子位置测量值，估计连续、平滑的位置和机械速度。相比对相邻位置直接差分，PLL 不会直接放大量化噪声和采样抖动，更适合作为速度环和 FOC 的反馈预处理环节。

本文由项目笔记整理，模型与参数尚未结合具体实现代码或实验数据核验，因此保留为 unverified。连续域结论只在 PLL 已锁定、环形误差处理正确且采样足够快等条件下近似成立。

  4. 将持续存在的位置误差积分为速度修正量。

  • 对静止位置输入，稳态位置误差为零；
  • 对恒定速度输入，稳态位置误差为零；

要点总结

编码器 PLL 的核心价值是用闭环位置观测器从离散位置中获得平滑的速度估计，并在跟踪能力和噪声抑制之间进行可调折中。理论分析与工程应用之间需要特别确认三件事：角度误差是否正确折返、参数使用的是 Hz 还是 rad/s，以及实际离散代码输出的速度状态是否与本文模型一致。
