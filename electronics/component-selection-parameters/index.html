常用元器件关键参数与选型检查表

发表于 2026-08-01 分类于 电子基础
覆盖 PPTC 与增强型 NMOSFET 的工程选型；器件原理、电源保护和 PCB 应用分别由关联文章维护。

本文以工程选型为目标，汇总自恢复保险丝和增强型 NMOSFET 的关键参数、额定值边界与常见降额原则。参数最终应以具体器件的数据手册和工作条件为准。

自恢复保险丝（PPTC）

  1. 保持电流：常温长期工作不动作的最大电流，选型：实际电流 ≤ 0.8×
  2. 动作电流：常温必触发保护的最小电流，
  3. 额定电压：长期耐压值，实际电压 ≤ ，分直流/交流款
  4. 最大故障电流：能承受的最大短路电流，短路电流≤此值才不烧毁
  5. 初始内阻：越小越好，导通损耗小、发热少
  6. 工作温度：-40~85℃，温度升高→降低、易误动作

NMOSFET（增强型）

  1. 阈值电压：使NMOS开始形成导电沟道的最小栅源电压，常温下典型值1~5V；温度升高时略有降低，易导致误导通。
  2. 漏源击穿电压：漏源之间能承受的最大反向电压，超过此值会导致器件击穿损坏；选型要求实际工作电压 ≤ 0.8×。
  3. 最大漏极电流：器件长期稳定工作能承受的最大漏极电流，超过此值会因发热烧毁；选型要求实际工作电流 ≤ 0.7×。
  4. 导通电阻：MOS管导通时漏源之间的等效电阻，越小，导通损耗（ ）越小；该参数随增大而降低，随温度升高而增大。
  5. 栅源击穿电压：栅源之间能承受的最大电压，因栅极氧化层极薄，典型值±10~±20V；超过此值会导致氧化层击穿，器件永久损坏，严禁超压。
  6. 开关时间（）
    • 开启时间：从栅压施加到漏极电流达到稳定值的时间；
    • 关断时间：从栅压移除到漏极电流降至截止值的时间；
      开关时间越短，器件适用于更高频率的开关电路。
  7. 工作温度范围：典型值-55~150℃，温度升高会导致下降、增大，需预留散热余量。
